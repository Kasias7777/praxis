# PRAXIS Marketing Insight — GitHub Pages

Gotowa statyczna witryna przygotowana dla repozytorium `praxis` i adresu:

`https://kasias7777.github.io/praxis/`

## Publikacja

Wgraj całą zawartość tej paczki bezpośrednio do głównego katalogu repozytorium GitHub `praxis`. Następnie w ustawieniach repozytorium wybierz **Pages → Deploy from a branch**, gałąź `main` i katalog `/ (root)`.

## Test lokalny

Folder strony powinien nazywać się `praxis`. Uruchom serwer z katalogu nadrzędnego:

```bash
python3 -m http.server 8000
```

Następnie otwórz `http://localhost:8000/praxis/`.

Czcionki Google Fonts wymagają połączenia z internetem; bez niego strona użyje czcionki zastępczej.
